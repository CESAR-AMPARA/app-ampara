# Product Guidelines: A.M.P.A.R.A.

## 1. Tone & Voice
- **Professional & Empathetic:** All copy within the application must remain formal, respectful, and focused on student well-being (Acolhimento). Communication should inspire trust for students while maintaining a serious, professional demeanor for school management and multidisciplinary teams.

## 2. Accessibility
- **Contrast & Scaling:** The platform must fully support high-contrast themes and scalable typography to ensure readability for visually impaired users.
- **Keyboard Navigation:** All interactive elements (forms, buttons, wizards) must be easily navigable using only a keyboard.

## 3. UI Design & Components
- **Material Design Inspired:** Interfaces should feature clean, card-based layouts with subtle shadows to establish hierarchy and focus. Components must be visually distinct and intuitive.

## 4. Interaction Patterns
- **Toast Notifications:** Use non-blocking, accessible toast notifications to provide immediate feedback on user actions (e.g., successful approval).
- **Asynchronous Updates:** Prioritize updating specific page sections via asynchronous API requests (like the Dashboard approvals) rather than relying on full page reloads.
- **Guided Wizards:** Use multi-step wizards for complex data entry tasks (like user onboarding) to reduce cognitive load.
